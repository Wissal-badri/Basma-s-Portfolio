# Basma's Portfolio 💜

A modern, responsive, and visually stunning personal portfolio for **Basma Aboubzou** (Fullstack Developer) built with React + Vite, styled using a luxury Purple & Lavender theme.

---

## ✨ Features

- 🌟 **Glowing Hero Section** with circular neon portrait aura, interactive role badge, and CV download.
- 📊 **Stats Bar** with frosted glass metric cards.
- 👩‍💻 **About Me** showcasing pillars, coding philosophies, and neon `{B}` creative workspace.
- 🛠️ **Skills & Capabilities** with interactive tech badges and glowing progress meters.
- 💼 **Recent Work / Projects** featuring interactive modals, tech stack tags, and live preview links.
- ⏳ **Experience & Career Timeline** with luminous node connections.
- 💬 **Client Testimonials** with avatars and carousel controls.
- 🚀 **Interactive Contact Modal** with instant form validation and celebration confetti.
- 📱 **Fully Responsive** across desktops, tablets, and smartphones.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Icons**: Lucide React
- **Effects**: Canvas Confetti
- **Styling**: Vanilla CSS Variables & Glassmorphism

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Wissal-badri/Basma-s-Portfolio.git
cd Basma-s-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
